جهش میان سیارات (Planet Jumping)

طراحی و توسعه توسط علیرضا کریمی

پروژه جهش میان سیارات یک تجربه سینمایی و تعاملی وب است که امکان سفر و کاوش در منظومه شمسی را از طریق پورتال سه‌بعدی محاسباتی فراهم می‌سازد. کلیه جلوه‌های فیزیک نور، زاویه چرخش با نشانگر ماوس و انیمیشن‌های مداری به صورت بومی و بدون کتابخانه خارجی پیاده‌سازی شده‌اند.

کنترل‌های ناوبری:

  • فهرست سیارات: با کلیک روی نام هر سیاره، مستقیماً به آن نقطه منتقل شوید.
  • پورتال مرکزی: کلیک روی پورتال یا عنوان آن، جهش مداری به مقصد بعدی را اجرا می‌کند.
  • کلیدهای ۱ تا ۸: دسترسی سریع صفحه‌کلید به سیارات ۱ تا ۸.
  • کلید Space / Enter: پرش از داخل پورتال.

⚡ آپلود خودکار با توکن گیت‌هاب و استقرار در کلودفلر اتوماتیک ۱-کلیک

با وارد کردن توکن گیت‌هاب، تمام فایل‌های پروژه (شامل کدهای سینمایی، کانفیگ کلودفلر، و مستندات علیرضا کریمی) به صورت مستقیم در اکانت شما آپلود شده و برای اجرای آنلاین در Cloudflare آماده می‌شوند.

🌟 روش رسمی: اتصال مستقیم گیت‌هاب به کلودفلر (GitHub Integration) توصیه شده

با این روش، هر زمان که کدی را در گیت‌هاب تغییر دهید یا Push کنید، کلودفلر به‌صورت کاملاً خودکار و رایگان سایت شما را بیلد و آپدیت می‌کند.

۱. یک مخزن (Repository) جدید در گیت‌هاب بسازید:
وارد github.com/new شوید و یک ریپازیتوری عمومی (Public) با نام دلخواه (مثلاً planet-jumping) بسازید.
۲. کدها را به گیت‌هاب ارسال (Push) کنید:
git init git add . git commit -m "Deploy Planet Jumping by Alireza Karimi" git branch -M main # آدرس ریپازیتوری خود را وارد کنید: git remote add origin https://github.com/USERNAME/planet-jumping.git git push -u origin main
۳. اتصال در پنل کلودفلر (Cloudflare Pages):
۱. وارد داشبورد کلودفلر شوید: dash.cloudflare.com
۲. از منوی سمت چپ به بخش Compute (Workers & Pages) بروید.
۳. دکمه Create application را بزنید و زبانه Pages را انتخاب کنید.
۴. روی گزینه Connect to Git کلیک کنید و حساب GitHub خود را متصل نمایید.
۵. مخزن planet-jumping را انتخاب کرده و Begin setup را بزنید.
۴. تنظیمات دقیق بیلد در کلودفلر (Build Settings):
Framework preset: Vite
Build command: npm run build
Build output directory: dist
(یا در صورت تمایل می‌توانید Framework preset را روی None بگذارید و Output directory را روی . قرار دهید)
۵. کلیک روی Save and Deploy:
کلودفلر در کمتر از ۳۰ ثانیه سایت شما را منتشر کرده و یک لینک اختصاصی و رایگان (مانند planet-jumping.pages.dev) با گواهینامه SSL به شما تحویل می‌دهد!
روش جایگزین: استقرار سریع با خط فرمان (Wrangler CLI) خط فرمان

بدون نیاز به تنظیمات وب، مستقیماً از طریق ترمینال پروژه را مستقر کنید:

npx wrangler pages deploy dist --project-name=planet-jumping
دانلود مستقیم فایل‌ها برای آرشیو یا آپلود دستی
