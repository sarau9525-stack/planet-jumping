# 🌌 جهش میان سیارات (Planet Jumping)
### پدیدآورنده و طراح: **علیرضا کریمی** (Alireza Karimi)

یک تجربه وب تعاملی و سه‌بعدی تمام‌صفحه برای کاوش و جهش در میان سیارات منظومه شمسی با پورتال ۳ بعدی محاسباتی، شبیه‌سازی اتمسفر و مشخصات علمی دقیق سیارات.

---

## 🚀 ویژگی‌های کلیدی
- **پورتال ۳ بعدی محاسباتی**: چرخش دینامیک با موقعیت ماوس و بردار فیزیکی با الگوریتم ژئومتری بدون وابستگی خارجی.
- **۸ سیاره منظومه شمسی**: عطارد، زهره، زمین، مریخ، مشتری، زحل، اورانوس، نپتون همراه با داده‌های علمی و تله‌متری دقیق به زبان فارسی.
- **انیمیشن جهش بین‌سیاره‌ای**: ورود و فرود به مدار هر سیاره همراه با پیش‌نمایش سینمایی.
- **صدای فضایی (Cosmic Drone)**: سنتز صدای فرکانس پایین جو کیهانی با Web Audio API.
- **طراحی تک‌فایلی مستقل (Zero-Build Ready)**: اجرای سریع روی Cloudflare Pages و GitHub Pages.

---

## ⚡ استقرار روی کلودفلر (Cloudflare Pages)

### روش اول: اتصال مستقیم گیت‌هاب (پیشنهادی)
1. مخزن را در داشبورد [Cloudflare Pages](https://dash.cloudflare.com/) با گزینه **Connect to Git** انتخاب کنید.
2. تنظیمات بیلد:
   - **Framework preset**: `Vite` یا `None`
   - **Build command**: `npm run build` (یا خالی)
   - **Build output directory**: `dist` (یا `.`)
3. دکمه **Save and Deploy** را بزنید.

### روش دوم: خط فرمان Cloudflare Wrangler
```bash
npx wrangler pages deploy dist --project-name=planet-jumping
```
